# Workout Tracker

A full-stack workout tracking application currently in development.

## Project goals

- Record workouts, exercises, sets, and reps
- Review workout history
- Track strength progress
- Build practical full-stack development experience

## Technology stack

- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Vitest
- Supertest
- React

## Current features

- Workout CRUD API
- Input validation and error handling
- PostgreSQL database persistence
- Separated routing, repository, and database logic
- Automated API testing with Vitest and Supertest

## Status

Work in progress. The backend is functional and tested, and the React frontend is currently being developed.
